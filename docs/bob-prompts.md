# IBM Bob Prompts

Use Bob IDE with the hackathon-provisioned account. Export relevant sessions into `bob_sessions/`.

## Session 1: Repository Analysis

```text
I am building CodeQuest Bob for the IBM Bob Hackathon.

The product is a gamified developer growth platform that helps developers level up inside real codebases. It turns repository context into growth quests: Repo Explorer, First Contributor, Incident Responder, and Developer Growth Passport.

Please analyze this repository and identify:
1. the main application structure,
2. likely entry points,
3. setup and run commands,
4. key files a new developer should inspect first,
5. documentation gaps,
6. test gaps,
7. beginner-friendly contribution opportunities,
8. realistic incident drill scenarios based on the app structure.

Do not modify files yet. Please only analyze and summarize.
```

## Session 2: Growth Quest Generation

```text
Based on the repository analysis, generate a growth quest path for CodeQuest Bob.

Create three levels:
1. Repo Explorer
2. First Contributor
3. Incident Responder

For each level, include:
- goal
- why it matters
- files to inspect
- commands to run
- success criteria
- XP value
- badge unlocked
- evidence for the Developer Growth Passport

Do not modify files yet.
```

## Session 3: Implementation Review

```text
Review this implementation for the IBM Bob Hackathon.

Check:
1. whether IBM Bob usage is clear,
2. whether the app demonstrates developer growth rather than only repo explanation,
3. whether the Developer Growth Passport is compelling,
4. whether the IBM ecosystem story is visible,
5. whether there are any security risks, especially committed secrets.

Do not modify files. Provide review findings and recommended fixes.
```
