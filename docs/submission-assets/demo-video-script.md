# CodeQuest Bob Demo Video Script

Target length: 4-5 minutes.

## 0:00 - 0:35 Opening

CodeQuest Bob is a developer growth platform for new contributors. Instead of only explaining code, it turns repository context into guided quests, learning recommendations, and a contribution-ready first PR package.

## 0:35 - 1:20 Repository Intake

Show the Home screen and start the repository scan. Explain that IBM Bob provides repository-aware context, then the product converts that context into an onboarding path.

## 1:20 - 2:05 Quest Map

Open the Quest Map. Show the four stages: Setup, Explore, Improve, and First PR. Highlight the Repository Orbit Map as a spatial way to understand the journey.

## 2:05 - 3:00 Quest Detail

Open Explore Quest. Show the objective checklist, Skill Boost Radar, and Bob Briefing. Explain how IBM services support learning recommendations and audio guidance, with graceful fallback when services are unavailable.

## 3:00 - 3:45 First PR Package

Open First PR Quest. Show the First PR Package: starter task, target files, commands, PR description, and checklist. This is the key artifact that turns onboarding into contribution readiness.

## 3:45 - 4:35 Developer Passport

Open Passport. Show XP, quest progress, Quest Badges, saved Skill Boosts, and AI Analysis Activity. Position this as growth evidence that can help contributors and maintainers.

## 4:35 - 5:00 Closing

Close with the line: Others explain code. CodeQuest Bob grows developers.
