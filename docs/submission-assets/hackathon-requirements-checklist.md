# IBM Bob Hackathon Submission Checklist

## Required Submission Fields

- Project title
- Short description
- Long description
- Technology and category tags
- Cover image
- Video presentation
- Slide presentation
- Public GitHub repository
- Exported IBM Bob session reports in `bob_sessions/`
- Demo application platform
- Application URL

## Judging Criteria Alignment

| Criterion | CodeQuest Bob Response |
| --- | --- |
| Application of Technology | IBM Bob is used as the repository-aware development partner, with exported task/session reports. IBM Granite, NLU, TTS, and STT support the product experience. |
| Presentation | The demo follows one path: Home → Scan → Quest Map → Quest Detail → First PR Package → Passport. |
| Business Value | Reduces onboarding friction, helps maintainers guide new contributors, and lowers the barrier to a first PR. |
| Originality | Combines Skill Boost Radar, Repository Orbit, First PR Package, and Developer Passport into a growth loop. |

## Final Tasks Before Submission

1. Export IBM Bob session reports and place them in `bob_sessions/`.
2. Confirm the GitHub repository is public.
3. Deploy the app and copy the public demo URL.
4. Record the video presentation using `demo-video-script.md`.
5. Upload the pitch deck from `codequest-bob-pitch-deck.pptx`.
