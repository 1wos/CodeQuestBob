# Product Brief

## Product

CodeQuest Bob

## One-Liner

CodeQuest Bob turns real repositories into gamified developer growth journeys powered by IBM Bob and the watsonx ecosystem.

## Core Idea

Most AI coding tools explain a repository or help write a PR. CodeQuest Bob focuses on the person growing inside the codebase.

The app creates a structured growth path:

1. Repo Explorer
2. First Contributor
3. Incident Responder
4. Developer Growth Passport

## User

- junior developers
- career switchers
- new team members
- first-time open-source contributors
- hackathon teammates joining an unfamiliar repository

## Differentiator

```text
Others explain code. CodeQuest Bob grows developers.
```

## MVP Screens

- Landing
- Repo Scan
- Growth Quest Map
- Repo Explorer Quest
- First Contributor Quest
- Incident Responder Quest
- Skill Boosts
- Developer Growth Passport
- IBM Ecosystem Showcase
- Bob Evidence Center

## Final Demo Promise

In under five minutes, the demo should show a developer moving from an unfamiliar repository to a visible Developer Growth Passport backed by IBM Bob evidence.
