# Skill Icons

Technology stack icons in this folder were downloaded from [Skill Icons](https://skillicons.dev/) for README, architecture, and article visuals.

They are used for non-IBM product stack items such as React, Vite, Three.js, Vercel, GitHub, TypeScript, and Node.js. IBM and Watson service icons remain in `docs/assets/ibm-icons` and `docs/assets/ibm-app-icons`.
