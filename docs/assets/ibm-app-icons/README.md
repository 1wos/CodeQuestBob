# IBM App Icon Assets

This folder contains selected Watson service SVG assets from the IBM Design Language App Icons Library.

- Source: https://www.ibm.com/design/language/iconography/app-icons/library/
- Icons used:
  - IBM Watson Natural Language Understanding
  - IBM Watson Text to Speech
  - IBM Watson Speech to Text
- Usage in this repo: README service strip and portfolio article visuals.

These assets are used to identify IBM services that power CodeQuest Bob's live learning recommendations and speech briefing loop. Product branding and trademark ownership remain with IBM.
