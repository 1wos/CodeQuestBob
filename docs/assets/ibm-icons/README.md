# IBM Icon Assets

This folder contains selected SVG assets from IBM's public IBM Cloud architecture icon repository.

- Source: https://github.com/IBM-Cloud/architecture-icons
- Reference direction: https://www.ibm.com/design/language/iconography/app-icons/library/
- Usage in this repo: README, architecture storytelling, and portfolio article visuals.

These assets are used to explain the CodeQuest Bob service architecture and IBM ecosystem integration. Product branding and trademark ownership remain with IBM.
